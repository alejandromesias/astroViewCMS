## Accepted limits and open calls (carry these forward)

- **Rename duplicate (2.10b, 2.10j):** a document the developer renamed upstream and the CMS then edited is recreated at its old path. 2.10j makes it visible as a warning. Git rename detection is a 50% similarity heuristic. The real fix (writing to the new path) changes the document key and belongs in phase 3.
- **Read-only and format limits (2.6b):** a referrer in a TOML or other format with no codec is invisible to the guard; read-only referrers are checked and answer `needsDeveloper`.
- **Windows tree kill (2.9c-A):** the grandchild test passes with the kill disabled on Windows; it proves the POSIX group kill only on Linux CI. The Windows `taskkill` command is pinned by a unit test only.
- **POSIX Ctrl-C (2.9c-A):** builds are now detached on POSIX, so Ctrl-C no longer reaches a build directly; `stop()` must kill the tree (2.9c-B does this).
- **Failed first build (2.9c-B):** if the first build at start-up fails, no node runs until a save asks for a rebuild or a publish runs. The design doesn't say what should happen; the user has not decided. Open question.
- **`--bundle` (2.9c-B):** turns the builder, every trigger, the start-up sweep and the astro check off. Intended for development and e2e.
- **2.10b departures (accepted, recorded in the 2.10b Result):** `collections` and `media` were optional (now required in 2.10i); a missing `cms/work` at start-up is set to `work-next`, not kept.
