## 2. Decisions and corrections made during wave 3

- **Dates in YAML are `Date` objects.** The plan first said the core schema leaves them strings. Astro's `parseYaml` uses `schema: 'core'`, `customTags: ['timestamp']`, `merge: true`; the codec uses the same. The correction is logged in 2.2b.
- **Cookie value is a token** (same format, 12 h life). An invalid `preview_token` is `401` with no fallback to the cookie. Redirect is `303`, relative, `no-store`.
- **A bundle is not self-running** (2.8b). It starts through `start.ts --out <bundle>`. Matters for the Phase 4 image (SYSTEM-DESIGN section 12).
- **The bridge's old `token` parameter** was a Phase 1 placeholder that never matched the gate; it is `preview_token` now, and a site's own `token` parameter passes through.
- **Bridge ordering:** listeners attach before the config fetch; otherwise the first load's `astro:page-load` (and the second `ready`) is lost.
- **Not enforced by a parser:** the YAML codec cannot write 4-space indent with unindented sequences (it indents them). The sample has no such file. Logged, documented later in `CMS-SERVER.md` (2.13b).
