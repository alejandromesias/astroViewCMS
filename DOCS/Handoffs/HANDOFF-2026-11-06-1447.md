## Watch out

- **Stryker:** only `node scripts/stryker-run.mjs <config> --mutate <file>` from the repo root, one file at a time, in the background. The tree must be clean (commit or stash first). A run can take up to 2 hours per file (`repo.ts` hit the 2-hour limit in 2.1h). Never run `npx stryker run` directly.
- **Git calls:** `runGit` prepends `-c protocol.ext.allow=never`, so `args[0]` is never the git command. Filter with `args.includes(...)`.
- **Haiku agent results list their departures from the plan.** Read the "Departures" and "Calls where the plan was open" lines before building on them. For example, 2.9a items 1 and 2 (`build.nodeModules`, the junction) were not built as written.
- **Hono:** an unhandled error becomes a plain 500 "Internal Server Error". The changes routes answer JSON on purpose.
- **Machine:** run `[build]` tasks alone.
- **Git config:** here `git config --get core.hooksPath` prints the absolute path of `.githooks`, not the relative one. Check it after any Stryker or vitest run.
- **Pre-commit hook:** runs typecheck, lint, format check and depcruise.
