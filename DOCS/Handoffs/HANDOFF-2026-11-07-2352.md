## The rules now in force

- **`main` is protected.** Merge commits only, no force push, no deletion. Required checks: `fast gates`, `e2e and browser`, `mutation on changed files`. Repository admins can bypass ("always"), which is why a direct push by the admin can still land.
- **Agents** commit and push their task branch on their own, open the pull request, read `fast`, `e2e` and `mutation-diff` with `gh pr checks`, fix on the branch, and report when it is green. They never push to `main`. **The user merges.**
- **Committing to `main`** only when the user names that commit in the same message. The CI-setup exception is gone.
- **Mutation floors:** a changed file under 80 blocks its PR. A file can be lowered only by a waiver in `.mutation-waivers.json` with a reason and the task that classified the survivors.
- **Local Stryker** only through `node scripts/stryker-run.mjs <config> --mutate <files>`, one file, on a clean tree, under about 10 minutes. Never `npx stryker run`.
- **Local tests:** run the test files for the feature, not the full Vitest suite. Exception: the full coverage run (`npm run coverage`) was run locally twice in this thread (q3 and q8), after the user said it was available.
- **Hooks:** `core.hooksPath` is `.githooks` (set per clone). The pre-commit hook runs both typechecks, `lint`, `format:check` and `depcruise`. The `reference-transaction` hook is the Stryker tripwire; keep the setting.
- **Pinned and ignored:** actions pinned by SHA; osv-scanner ignores `GHSA-g3hv-75wg-m249` (minimatch, dev only) until 2026-12-15 (reminder in the phase 0-1 open items); TypeScript 7 is out until dependency-cruiser supports it.
- **Line endings** are LF everywhere.
