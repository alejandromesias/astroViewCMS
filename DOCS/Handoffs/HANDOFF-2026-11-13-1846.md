## Wave 10: decisions that shape later work

- Publish builds the squash with plumbing. Its parent is the merge base of `cms/work` and `origin/<branch>`, not the tip. The push is never forced. The author is `git.author`.
- Push races: sync and retry up to 3 times, then `502`. A retry does not revalidate. A retry whose sync brought new code stops with `503 upstream-changed`.
- Publish releases the lock during the rebuild wait (2.10d item 4).
- `status.publish` is `{ state, error }`. `409 referenced-by`, `422`, `503 busy` and `503 build-in-progress` set it back to `idle`.
- 2.10g: a failed first build is never rebuilt automatically. A call after a lapsed session restarts the poll one interval later, even with a back-off pending.
- Flake, unresolved: one unexplained failure in the `run.test.ts` first-start test. An explicit 5 s timeout was added. Five isolated runs and two full-file runs passed afterwards.
