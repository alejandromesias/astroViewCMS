## What the project is

A single-tenant CMS for Astro sites that scales to multi-tenant. A preview node
renders any page of the user's site with unsaved drafts, in memory, without
rebuilding. The units: **document** (edit, draft, validate, save), **page**
(render), **region** (DOM patch hint only), **changeset** (publish). Islands as
a save unit were a mistake and are gone.

## Decisions worth knowing before touching anything

- **D2:** drafts render with the site's own Markdown plugins and Shiki. Cost is
  the `astro.config` import (~1 s, ~88 MB), not Shiki. Code fences outside the
  built-content language list (plus optional `extraLanguages`) render as
  `text` and report `code-language:<lang>` in `limits`. Plain code blocks only
  if the config import or a plugin throws (`markdown-plugins`).
- **D11:** MDX drafts show the saved body plus `mdx-body` in `limits`.
- **D12:** images come from the request's media map and bypass the optimizer.
- **D13:** JSON, YAML, Markdown and MDX are editable; others are listed with
  `editable: false`. A save never converts formats.
- **Deviation:** `trailingSlash` is not enforced on incoming preview paths.
